# Kairo Quick Capture

Version: 3.4.39

Capture fleeting thoughts quickly and deliver them safely to an inbox or daily note.

## Pricing and usage

The verified active one-time Paddle offers are:

| Price | Included native units |
| ---: | ---: |
| $1 USD | 100 credits |
| $10 USD | 1,000 credits |

Capture units are quoted by the server for each exact result; the plugin shows free and purchased units before reveal. The plugin loads current price and product details from Constance/Paddle and displays the confirmed amount and native units before checkout. Prices and availability shown in Obsidian are current at purchase time.

## Installation

In Obsidian, open **Settings → Community plugins → Browse**, search for **Kairo Quick Capture**, install it, and enable it.
