# Privacy

Kairo keeps capture content local. Optional billing requests go only to TutivSoft Constance and contain the fixed app id `kairo-quick-capture`, a random installation id, a one-credit spend amount, and an idempotency event id. Captured text is never included in billing requests. Checkout may receive the billing email entered by the user for a receipt. See the repository `PRIVACY.md` for the full threat model.
